## 2. Формат

- Заняття проходять онлайн, наживо, у групі з тренером.
- Обсяг: 15 занять, 30 годин.
- Одне заняття триває 120 хвилин: теорія — 60 хвилин, розбір коду — 45 хвилин, запитання й відповіді — 10 хвилин.
- Заняття має дві частини: теорія зі слайдами і лайфкодинг — тренер наживо розв'язує з агентом заздалегідь описану задачу і коментує рішення.
- Усі заняття записуються; запис доступний для повторного перегляду.
- Між заняттями: квіз; домашнє завдання у двох рівнях — base і pro; перевірка кожного домашнього завдання.
- Перше заняття проходить у Microsoft Teams. Платформу решти занять не названо.

## 4. Аудиторія і рівні

- Курс має два рівні підготовки в одному потоці.
- Рівень 1 — розробники-початківці: знайомі з Python, вебфреймворків майже не торкались.
- Рівень 2 — джуни з досвідом і мідли: вже працюють з вебом і хочуть системно опанувати агентну розробку.
- Теорія спільна; рівні відрізняються завданнями (base і pro) та Advanced-блоком.
- Advanced-блок — чотири заняття наприкінці курсу, розраховані на рівень 2. Вони викладені покроково, тож розібратися може і новачок.

Вимоги до вступу:

| Область | Рівень 1 | Рівень 2 |
| :-- | :-- | :-- |
| Python | базовий рівень: функції, класи, колекції, винятки, робота з файлами; віртуальні середовища, встановлення пакетів, запуск скриптів | те саме і досвід реальних проєктів: типізація, декоратори й генератори; базове знайомство з pytest |
| Веб | не обов'язково; допоможе базове уявлення про HTML | основи HTTP і REST: методи, статуси, JSON; знайомство щонайменше з одним фреймворком (FastAPI, Flask, Django) |
| Бази даних | не обов'язково: старт із поясненнями | базовий SQL на рівні читання: SELECT, JOIN |
| Git | clone, add і commit, push, робота в гілці | те саме і робота через pull request на GitHub |
| Оточення | термінал на базовому рівні; Python 3.14, git, редактор або IDE | те саме і Docker на рівні `docker compose up` |
| Акаунти | GitHub і акаунт одного з трьох агентів | GitHub і бажано доступ до двох-трьох агентів |

## 5. Інструменти і технології

- Кодинг-агенти: Claude Code (Anthropic), Codex (OpenAI), Antigravity (Google) — у консольному, IDE- і хмарному варіантах.
- Студент проходить курс одним обраним інструментом; демонстрації показують усі три.
- Принцип курсу: «агент замінюваний — процес ні».
- Стек: Python 3.14, FastAPI, SQLAlchemy 2.x, pytest, ruff, mypy, uv.
- Бази даних: PostgreSQL; Docker — на рівні pro.
- Безперервна інтеграція: GitHub Actions.
- Основний матеріал від мови програмування не залежить; Python обрано для демонстрацій і завдань.

## 6. Програма

**Блок I. Агент зблизька**

1. Як думає кодинг-агент.
2. Мова, якою ставлять задачі.
3. Три агенти — один процес.

**Блок II. Проєкт, зрозумілий агенту**

4. Файли, які агент читає першими.
5. Спершу план, потім код.
6. Агент з інструментами: MCP і скіли.

**Блок III. Довіра через перевірку**

7. Тести пишуться першими.
8. Гейти: зелене або нічого.
9. Полювання на баги разом з агентом.

**Блок IV. Більше рук: паралельність і продукт**

10. Оркестр агентів.
11. LLM всередині застосунку.

**Advanced-блок. Автономія під контролем**

12. Задача, яку агент виконує самостійно.
13. Рев'ю-бот у CI.
14. Довгий забіг.
15. Капстоун: wow-фіча.

## 7. Проєкти і сертифікат

- Проєктів три: лекційний, домашній, фінальний.
- Лекційний проєкт — «Смакотека», кулінарна книга: рецепти, меню тижня, список покупок, LLM-імпорт рецептів. Тренер будує його з агентами наживо.
- Домашній проєкт — «Полиця», домашня бібліотека: каталог, журнал читання, добірки, позички, статистика. Наприкінці курсу це завершений робочий застосунок у портфоліо.
- Для текстів: у студента два власні проєкти — домашній («свій проєкт упродовж курсу») і фінальний («випускний — повністю самостійно»); лекційний проєкт веде тренер.
- Фінальний проєкт — самостійний, одна з чотирьох тем: «Спільно» (волонтерський хаб), «Верстат» (облік майстерні), «Смакотека+», «Полиця+». Дві останні — розвиток наявної кодової бази; беруться за погодженням з ментором.
- Строк фінального проєкту: два тижні після п'ятнадцятого заняття; проєкт завершується захистом.
- Якщо студент не встиг до захисту: групи стартують щомісяця, захиститися можна з будь-якою наступною групою протягом шести місяців.
- Сертифікат видає навчальний центр CBS за результатами онлайн-тестування. Тести CBS складає для цього курсу на основі його квізів.

## 9. Що студент уміє після курсу

1. Ставити агентові задачі за структурованим шаблоном так, щоб результат був передбачуваним.
2. Готувати репозиторій до роботи агента: файли-інструкції (AGENTS.md і власні формати Claude Code, Codex, Antigravity), структура Python-проєкту, правила.
3. Працювати через план: погоджувати план до коду, правити його, відкочуватись і перезапускати.
4. Будувати систему довіри до результату: тести як контракт, лінтери й типізація, pre-commit і CI — гейти, які агент проходить сам.
5. Налагоджувати код агента і проводити рев'ю: типові помилки AI-коду, гіпотезний пошук багів, чек-лист рев'ю.
6. Керувати кількома агентами: субагенти, паралельні сесії, патерн «виконавець/рецензент».
7. Вбудовувати велику мовну модель у власний застосунок: structured output, обробка помилок, контроль вартості, тестування з моками.
8. На рівні pro і в Advanced-блоці: делегувати задачі автономним агентам через Issue з критеріями приймання, налаштовувати рев'ю-бота в CI, запускати довгі автономні сесії із зовнішньою пам'яттю.

## 10. Як писати

| Що | Як писати | Чого не писати |
| :-- | :-- | :-- |
| Відкритість занять | «перше відвідування заняття відкрите для всіх, хто зареєструвався протягом перших трьох занять»; поруч із дедлайном — «…хто зареєструвався до 4 листопада включно» | «усі заняття відкриті», «заняття 2 і 3 відкриті», «безкоштовно» |
| Проєкти студента | «свій проєкт упродовж курсу і випускний — повністю самостійно» | «два повноцінних проєкти» без пояснення |
| Постановка задачі агентові | «специфікація» — опис того, що будуємо, до коду; шаблони `docs/templates/task-template.md` і `spec-template.md` | — |
| Дата завершення курсу | «орієнтовно в середині грудня» | точної дати останнього заняття чи захисту |
| Рівень 1 | «знайомі з Python» | «впевнено пишуть базовий Python» |
| Бази даних | PostgreSQL | SQLite |
| Ціна | «умови й вартість — на сторінці курсу» з посиланням на сторінку курсу | сум, валют, умов оплати частинами |
| Одиниця навчання | «заняття» | «лекція» — лише в назвах програми |
| Платформа | Microsoft Teams — для відкритих відвідувань занять | платформи решти занять |
| Сертифікат | «за результатами онлайн-тестування»; видає CBS | що сертифікат видається за результатами захисту фінального проєкту |
