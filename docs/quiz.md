# Мінітест рівня

**Версія 0.3 · 20.10.2026 · тексти порад — за генеральною репетицією** · межі рівнів і результати погоджено з оператором 13.10. Використовує фіча Ф3 (Issue): п'ять запитань → рівень і порада; результат зберігається в учасника (`level`). Результати прив'язані до рівнів курсу (`course.md`, розділ 4).

## Правила

- П'ять запитань, у кожного три варіанти; один вибір.
- Бали варіантів — 0, 1 або 2; сума — від 0 до 10.
- Рівень за сумою: 0–4 — `level1`; 5–7 — `level1_plus`; 8–10 — `level2`. Окремого результату «ще не для курсу» немає: вимогу базового Python називає порада `level1`.
- Повторне проходження перезаписує результат.
- Людина бачить лише назву результату і пораду; бали і значення в базі не показуються.
- У базу записується лише значення рівня (поле `level` учасника, у CSV — стовпець `level`); бали не зберігаються.

## Запитання

### 1. Як ви зараз пишете на Python?

- Ще не пишу або лише починаю — 0
- Пишу скрипти: функції, класи, колекції — 1
- Роблю проєкти: типізація, пакети, віртуальні середовища — 2

### 2. Що ви знаєте про веброзробку?

- Майже нічого — 0
- Знаю, що таке HTTP, JSON і REST; пробував вебфреймворк — 1
- Працюю з FastAPI, Flask або Django — 2

### 3. Як ви працюєте з git?

- Не користуюсь — 0
- clone, commit, push, гілки — 1
- Pull request на GitHub і рев'ю — звична справа — 2

### 4. Чи працювали ви з кодинг-агентами?

- Ні, або лише питав код у чаті — 0
- Пробував Claude Code, Codex чи Antigravity на невеликих задачах — 1
- Регулярно ставлю агентам задачі в реальному проєкті — 2

### 5. Як ви перевіряєте свій код?

- Запускаю і дивлюся, чи працює — 0
- Іноді пишу тести або запускаю наявні — 1
- pytest, лінтер і CI — звичайна частина роботи — 2
